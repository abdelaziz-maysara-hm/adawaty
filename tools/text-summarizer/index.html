تلخيص النصوص بالذكاء الاصطناعيAI Text Summarizer

لخّص أي نص طويل تلقائيًا بالذكاء الاصطناعي، يعمل بالكامل داخل متصفحك بدون سيرفر.Automatically summarize any long text with AI, running entirely in your browser with no server.

متصفحك لا يدعم النسخة المحليةYour browser doesn't support the local version

أداة التلخيص المحلية تحتاج متصفحًا يدعم WebGPU (مثل أحدث إصدارات Chrome أو Edge). ممكن بدلًا من كده تجرّب النسخة السحابية (بترسل نصك لخدمة ذكاء اصطناعي سحابية).The local Summarizer needs a browser that supports WebGPU (such as a recent version of Chrome or Edge). You can instead try the cloud version (which sends your text to a cloud AI service).

الأسئلة الشائعةFrequently Asked Questions

هل استخدام أداة التلخيص مجاني بالكامل؟Is the AI Text Summarizer completely free?

نعم، بدون أي رسوم مخفية أو حاجة لإنشاء حساب أو تثبيت أي برنامج.Yes, with no hidden fees, no account required, and nothing to install.

هل يتم إرسال نصي إلى خادم خارجي؟Is my text sent to an external server?

افتراضيًا لا؛ يعمل نموذج الذكاء الاصطناعي بالكامل داخل متصفحك على جهازك ونصك لا يُرسل لأي خادم. توجد نسخة سحابية اختيارية (أسرع، بدون تحميل موديل) تختارها بنفسك صراحةً، وفيها فقط يُرسل النص لخدمة سحابية.By default, no; the AI model runs entirely inside your browser and your text is never sent to any server. An optional cloud version (faster, no model download) exists that you explicitly choose yourself, and only then is your text sent to a cloud service.

ليه أول استخدام بيحمّل حاجة؟Why does the first use download something?

أول استخدام بيحمّل نموذج ذكاء اصطناعي (حوالي 950 ميجابايت) بيتخزن بعدها في متصفحك، فكل استخدام بعد كده بيبدأ فورًا. ده محتاج متصفحًا يدعم WebGPU.The first use downloads an AI model (about 950 MB) that your browser then caches, so every use after that starts instantly. This requires a browser that supports WebGPU.
