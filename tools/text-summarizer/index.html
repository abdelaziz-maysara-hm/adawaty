لخّص أي نص طويل تلقائيًا بالذكاء الاصطناعي، يعمل بالكامل داخل متصفحك بدون سيرفر.Automatically summarize any long text with AI, running entirely in your browser with no server.

متصفحك لا يدعم هذه الأداةYour browser does not support this tool

أداة التلخيص تحتاج متصفحًا يدعم WebGPU (مثل أحدث إصدارات Chrome أو Edge). جرّب تحديث متصفحك أو استخدام متصفح آخر.The Summarizer needs a browser that supports WebGPU (such as a recent version of Chrome or Edge). Try updating your browser or using a different one.

الأسئلة الشائعةFrequently Asked Questions

هل استخدام أداة التلخيص مجاني بالكامل؟Is the AI Text Summarizer completely free?

نعم، بدون أي رسوم مخفية أو حاجة لإنشاء حساب أو تثبيت أي برنامج.Yes, with no hidden fees, no account required, and nothing to install.

هل يتم إرسال نصي إلى خادم خارجي؟Is my text sent to an external server?

لا، يعمل نموذج الذكاء الاصطناعي بالكامل داخل متصفحك على جهازك؛ نصك لا يُرسل لأي خادم أبدًا.No, the AI model runs entirely inside your browser on your own device; your text is never sent to any server.

ليه أول استخدام بيحمّل حاجة؟Why does the first use download something?

أول استخدام بيحمّل نموذج ذكاء اصطناعي (حوالي 950 ميجابايت) بيتخزن بعدها في متصفحك، فكل استخدام بعد كده بيبدأ فورًا. ده محتاج متصفحًا يدعم WebGPU.The first use downloads an AI model (about 950 MB) that your browser then caches, so every use after that starts instantly. This requires a browser that supports WebGPU.
