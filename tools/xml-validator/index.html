التحقق من صحة بنية XMLXML Well-Formedness Validator

تأكد أن مستند XML صحيح البنية: وسوم متطابقة، عنصر جذر واحد، ولا وسوم غير مغلقة.Check that an XML document is well-formed: matching tags, a single root element, and no unclosed tags.

هذا فحص بنية أساسي فقط، وليس تحققًا كاملًا من مخطط XSD.This is a basic structural check only, not full validation against an XSD schema.
