ما الذي يعمل الآن؟ What works today?

هذه معاينة صادقة للحالة الفعلية داخل المستودع. An honest preview of the repository's current state.

01

محرك الأدوات Tool runtime

تسجيل الأدوات، التحميل، دورة الحياة، العزل، الجدولة، الحالة والمعاملات الذرّية. Registration, loading, lifecycle, sandboxing, scheduling, state and atomic transactions.

02

الحوكمة والمراقبة Governance & observability

سياسات وصلاحيات، تدقيق، تشخيص، قياسات تشغيلية وتتبع للأخطاء. Policies, permissions, auditing, diagnostics, runtime metrics and error tracing.

03

التحقق المستمر Continuous verification

فحص Syntax واختبارات تكامل تعمل تلقائيًا قبل نشر أي تحديث على GitHub Pages. Syntax checks and integration tests run automatically before every GitHub Pages deployment.
